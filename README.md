# Portfolio Website

A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS. Designed for easy deployment on Vercel with future AI agent integration capabilities.

## Features

- 🎨 Beautiful, modern UI with smooth animations
- 📱 Fully responsive design
- ⚡ Fast and optimized with Next.js
- 🤖 Ready for AI agent integration
- 🌙 Smooth scrolling and transitions

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
npm run build
npm start
```

## Deployment on Vercel

1. Push your code to GitHub
2. Import your repository in Vercel
3. Vercel will automatically detect Next.js and configure the build settings
4. Deploy!

Or use the Vercel CLI:

```bash
npm i -g vercel
vercel
```

## Customization

Edit the data files in `/data` directory to customize your portfolio information:
- `personalInfo.ts` - Personal information and contact details
- `experience.ts` - Work experience
- `projects.ts` - Projects showcase
- `skills.ts` - Skills and technologies

## Future AI Agent Integration

The portfolio is structured to easily integrate an AI agent. The `AIAgent` component placeholder is ready in the components directory for future implementation.
